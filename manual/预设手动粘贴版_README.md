# 修仙D20｜两套规则模板（手动粘贴版）

本目录只提供两套 D20 规则模板，不包含、复制、修改或冒用任何第三方预设。

## 两套模板

1. `修仙D20·核心裁判系统`
   - 文件：`assets/prompts/d20-core.txt`
   - Role：`system`
   - 推荐位置：放在 Main Prompt 之后、其他剧情/世界设定之前。

2. `修仙D20·每轮强制检查`
   - 文件：`assets/prompts/d20-guard.txt`
   - Role：`system`
   - 推荐位置：放在靠近聊天历史末端的位置，通常在 Chat History 之后、Post-History Instructions / Jailbreak 之前。

## 使用原则

- 手动粘贴时，只需要添加上面这两条 D20 Prompt。
- 不需要导入任何所谓“某某预设 + D20”。
- 本项目没有包含任何第三方预设原版，也不会声称包含。
- 如果使用扩展自动版，则这两套规则会由扩展直接注入，不需要再手动粘贴。
- 不要同时保留旧版 D20 规则和新版 D20 规则，避免重复约束。

## 天道点自动奖励说明

`d20-guard.txt` 已包含以下规则：突破 +1、完成新秘境 +1、首次征服新的女修 +1。

但真正的“自动加点、去重、5点上限与隐藏奖励协议清理”由扩展中的 `tiandao-runtime.js` 执行。
因此：

- 使用 GitHub 扩展自动版：天道点会自动入账。
- 只手动粘贴两段 Prompt、但没有安装扩展运行时：模型仍可能输出 `[D20_TIANDAO_AWARD]` 标记，但不会有脚本替你自动修改天道点。

## 关于“只保留两套模板”

这里的意思是：本项目提供的 D20 规则内容只有上述两套，不夹带其他预设内容。
扩展不会删除用户 SillyTavern 中原本已经存在的其他预设或配置。
